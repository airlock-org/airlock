Original Airlock code uses the [MIT license](../LICENSE). Dependencies, firmware,
artwork, and third-party source retain their own licenses and redistribution
requirements.

AirlockOS builds on NixOS, Qubes, Xen, libvirt, and GNOME. The website uses the
Inter typeface under the SIL Open Font License 1.1.

The vendored `nixos-qubes` source has unresolved licensing terms that need
clarification before public redistribution. Airlock's MIT license does not
cover that source or grant redistribution rights for the complete OS image.

For dependency attribution and license notices, see
[Third-party source and attribution](../THIRD_PARTY.md) in the repository.
